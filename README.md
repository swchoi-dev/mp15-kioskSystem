# mp15-kioskSystem
[메플 15기 1차 정규평가] - 키오스크 시스템 구현

### 구현 내용
올리브영 천호점 키오스크

```text
====================================                                            
         올리브영 천호점                                                        
====================================                                            
[상품목록]                                                                      
1. 메디힐 콜라겐 마스크 팩 (마스크팩)  3000원  [3개 이상 10% 할인]              
2. 메디힐 풀에너지 10개 (마스크팩)  8000원  [정가]                              
3. 밀크바디 (바디케어)  3500원  [10개 이상 구매 시 개당 1000원 할인]            
4. 셀퓨전씨 선크림 SPF+++ (스킨케어)  13000원  [3개 이상 10% 할인]              
5. 탈모 방지 남성용 헤어샴푸 (헤어케어)  30000원  [2개 구입 시 1개가 무료]      
6. 아크네스 포밍 클렌져 2개 (클렌징)  13000원  [정가]                           
------------------------------------                                            
[장바구니]                                                                      
------------------------------------                                            
1. 담기   2. 전체 비우기   3. 결제   4. 영업 종료                               
번호 :                            
```

### 클래스 계층 구조
```text
Program : 메인 프로그램

ConsoleInput : 사용자 입력 처리

KioskMenu : 키오스크 메뉴 열거형

ItemCategory : 아이템 카테고리 열거형

Item - 상품 추상클래스
├── BodyLotion
├── Cleansing
├── MaskPack
├── Shampoo
└── SunCream

Promotion - 할인 행사 추상 클래스
├── BasicPromotion : "3개 이상 10% 할인
├── BigSalePromotion : 10개 이상 구매 시 개당 1000원 할인
├── EmptyPromotion : 정가
└── PlusPromotion : 2개 구입 시 1개가 무료
```
